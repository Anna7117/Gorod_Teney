# **Приложение-игра "Город Теней"**
Вы играете за Смотрителя Станции — последнего, кто ещё способен вернуть свет в Город Мутных Огней. Когда-то этот город сиял яркими башнями, вывесками и бесконечными огнями, однако со временем улицы погрузились в холодный туман и темноту. Почти все источники света погасли, а жители давно покинули городские районы.
Главная задача игрока — пройти три района города, собрать монетки и найти ключ на каждом уровне. Без найденного ключа дверь на следующий уровень не откроется. После прохождения всех уровней включается главный генератор, и город снова начинает освещаться.

Данная игра является 2D-платформером с элементами аркады и приключения. Основой игрового процесса выступает прохождение уровней с использованием различных механик передвижения персонажа. Игроку предстоит перепрыгивать препятствия, исследовать локации, собирать предметы и избегать опасностей. В игре присутствуют два режима сложности. Лёгкий режим позволяет спокойно познакомиться с механиками игры без врагов, а сложный превращает прохождение в более напряжённое испытание благодаря появлению Гудящей Тени, преследующей игрока на протяжении уровней.

# **Управление**
Для игры потребуется клавиатура.
* Клавиши "A" и "D" или стрелки влево и вправо — движение персонажа
* Клавиша "W", стрелка вверх или “Пробел” — прыжок
* Клавиша "Esc" — открытие меню паузы

# **Технологии**
В проекте использовались основные технологии для создания 2D-платформера:
* Игровой движок "Godot Engine 4"
* Язык программирования "GDScript"
* Система 2D физики: встроенная в Godot (CharacterBody2D, Area2D)
* "TileMap" для создания игровых уровней
* "ParallaxBackground" для создания эффекта глубины фона
* "AnimationPlayer" и "AnimatedSprite2D" для анимаций и визуальных эффектов
* "ConfigFile" для системы сохранений
* "GitHub" для хранения проекта и контроля версий

# **Установка**
Для установки игры следуйте инструкции:
*	Перейдите по ссылке ()
*	Скачайте архив с игрой «Город Теней».
*	Распакуйте архив в удобную папку на компьютере.
*	Откройте распакованную папку.
*	Запустите исполняемый файл игры с расширением .exe.

Важно: не удаляйте файлы, находящиеся внутри папки проекта, поскольку это может привести к неправильной работе игры или ошибкам при запуске.

В итоге был создан полноценный игровой проект с несколькими уровнями, двумя режимами сложности, системой сохранений и завершённой финальной сценой. Приятной игры!
